# 🕵️ Danh sách 144 AI Agents (Agency-Agents Overview)

Dưới đây là danh sách tổng hợp toàn bộ các "Chuyên gia AI" từ thư viện `agency-agents`.
Bạn hãy lướt qua cột **Specialty (Chuyên môn)** và **When to Use (Khi nào cần dùng)** để tick [x] chọn ra những Agent phù hợp với dự án `Ai-Agent` của chúng ta nhé.
